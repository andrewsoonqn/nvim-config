# Archived Neovim plugins

These plugin configurations are retained for reference but are not loaded by Neovim.

To restore one:

1. Move its file back to the matching directory under `lua/plugins/`.
2. Add its `require` entry to `lua/lazy-plugins.lua`.
3. Run `:Lazy sync`.
